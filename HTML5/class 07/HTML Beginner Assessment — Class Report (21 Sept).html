What to do next

  • "href" is still the single worst-spelt attribute in the class — herf, hrep, sre. It's the same fault as the 14 September batch. Worth a five-minute drill at the start of the next lesson specifically on this one word, since it's costing marks across nearly every link question.
  • The "=" sign is being dropped between attribute name and value in a large minority of papers — type"text", src picture.jpg, target-blank. Jahangir Khan and Ibrahim Khan lose most of their coding marks to this single habit. Show the shape as name=value with no gaps.
  • <th> is still being skipped in most tables — students build correct rows and cells but leave the header row as plain <td>. Same fix as last time: a short table-only drill with a required header row.
  • Four students need a re-test: SHOAIB REHMAN (33.5), Hameed ullah (41.5), awais (43.5), and Muhammad idrees (48). All four are inventing tag names that don't exist (<hyref>, <selected>, <optional>) rather than misspelling real ones — a sign they haven't yet memorised the actual tag set. Best fixed with copy-then-modify exercises before a re-sit.
