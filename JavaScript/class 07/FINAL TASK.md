PART 1: IF / ELSE (Basic Practice)

Q1. Age Checker

User se age input lein. Agar age 18 ya us se zyada hai to "You are eligible" show karein, warna "You are not eligible".

User se number input lein. Agar number 100 ke equal hai to "Correct Number" show karein, warna "Wrong Number".

Q5. Shopping Checker

PART 4: LOGICAL OPERATORS (&& AND ||)

Q14. Login System (AND)

User se username aur password input lein.

Agar username "admin" AND password "12345" ho to "Login Successful" show karein, otherwise "Login Failed".

Q15. Gender Checker (OR)

User se gender input lein.

Agar gender "male" OR "female" ho to "You are allowed" show karein, otherwise "Not Allowed".

Q16. Admission Checker (AND)

User se age aur marks input lein.

Agar age 18 ya us se zyada AND marks 60 ya us se zyada hon to "Admission Allowed" show karein, otherwise "Admission Rejected".

Q17. Discount Checker (OR)

User se shopping amount aur customer status input lein.

Agar amount 10000 se zyada OR customer status "VIP" ho to "Discount Available" show karein, otherwise "No Discount".

Q18. Job Eligibility (AND)

User se age aur experience input lein.

Agar age 22 ya us se zyada AND experience 2 years ya us se zyada ho to "Eligible for Job" show karein, otherwise "Not Eligible".
